## 边角约定

网段统一用字典表示，键固定为 `network`、`prefix`、`version`：`network` 是规范化的地址字符串，`prefix` 是网络位数整数，`version` 是 4 或 6。输出必须是新对象，不原地修改输入。

1. 主机位校验：`parse_cidr` 对显式前缀执行严格校验，主机位非零即拒绝；`normalize` 则负责把主机位清零，两者职责不能混。
2. 前缀合法性：前缀必须在 0 到 32（IPv4）或 0 到 128（IPv6）闭区间内，越界或无法解析都抛 `ValueError`。
3. 裸地址补满前缀：不带斜杠的单地址按满前缀处理，IPv4 为 32，IPv6 为 128；不得把裸地址当成零前缀或任意前缀。
4. 规范化：`normalize` 清除主机位并输出规范地址字符串，例如 10.0.0.1/24 与 10.0.0.99/24 都归一到 10.0.0.0/24，保证同一网段只有一种写法。
5. 包含判定：`covers(a, b)` 按网络位数比较，包含同网段、网络地址和广播地址；不得用字符串 startswith 比较，10.0.1.0/24 属于 10.0.0.0/23。
6. 相邻判定：`adjacent(a, b)` 要求同地址族、同前缀长度，且两个网络地址只在共同前缀之后的最后一位不同，等价于异或结果恰好等于该前缀对应的块大小；前缀 0 不可能再合并。
7. 包含剔除：归并时先去掉重复项和被其他网段包含的网段，再合并相邻项；被包含项无论出现在输入前部还是后部都必须消失。
8. 多轮合并：一轮合并产生的新网段可能继续与同层网段相邻，必须重复剔除与合并直到结果稳定，四个连续的 /24 要得到 /22，不能停在两个 /23。
9. 输出顺序：`collapse` 与 `sort_nets` 均按网络地址数值升序排列，同一网络地址按前缀长度升序；不得按字符串排序，10.0.2.0 必须排在 10.0.10.0 前面。
10. 空集合：`collapse([])` 返回空列表，不抛异常；批量输入中的空列表也返回空列表。
11. 重复项：完全相同的规范化网段只保留一个，重复项不得让归并结果变长。
12. 地址族隔离：IPv4 与 IPv6 不得混合归并；`validate_list` 返回混合族问题，`collapse` 遇到混族输入抛 `ValueError`。
13. 校验问题码：`validate_list` 返回去重后的稳定问题码，按 `host_bits`、`mixed_family`、`prefix_out_of_range` 的顺序排列；没有问题时返回空列表。
14. 单地址输出：单个 IPv4 地址表示为 32 位前缀，单个 IPv6 地址表示为 128 位前缀，任何路径都不能丢掉满前缀。
15. 边界地址：`covers` 包含网络地址与广播地址，10.0.0.0/24 同时覆盖 10.0.0.0 和 10.0.0.255，但不覆盖 10.0.1.0。
16. 批量独立：`cidr_batch` 返回 `{"policy": 策略, "results": [...]}`，每个输入列表单独归并，后一个列表不得复用前一个列表的中间结果，整体结果必须与逐个调用 `collapse` 相同。
